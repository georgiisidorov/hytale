# Инструкция по экспорту структуры из Minecraft

## ✅ Координаты структуры в Minecraft

**Угол 1 (Corner 1):** `10 -60 13`  
**Угол 2 (Corner 2):** `-28 -59 -33`

**Границы структуры:**
- X: от **-28** до **10** (ширина: 39)
- Y: от **-60** до **-59** (высота: 2)  
- Z: от **-33** до **13** (длина: 47)

**Origin (минимальный угол для Structure Block):** `-28 -60 -33`

---

## 📋 Способ 1: Structure Block (рекомендуется)

### Шаги:

1. **Откройте Minecraft** и зайдите в мир "Новый мир"

2. **Найдите структуру** по координатам (используйте F3 для отображения координат)

3. **Получите Structure Block:**
   ```
   /give @s structure_block
   ```

4. **Поставьте Structure Block** в точке `-28 -60 -33` (или рядом с этой точкой)

5. **Откройте интерфейс** Structure Block (ПКМ)

6. **Настройки:**
   - **Режим:** `Save` (Сохранить)
   - **Structure Name:** `minecraft_structure` (или любое имя)
   - **Relative Position:**
     - X: `0`
     - Y: `0`  
     - Z: `0`
   - **Structure Size:**
     - X: `39`
     - Y: `2`
     - Z: `47`
   - **Include Entities:** по желанию (обычно выключено)
   - **Show Bounding Box:** включите для визуализации границ

7. **Нажмите кнопку `SAVE`**

8. **Файл будет сохранён в:**
   ```
   ~/.minecraft/saves/Новый мир/generated/structures/minecraft_structure.nbt
   ```

---

## 📋 Способ 2: Команда /structure (Minecraft 1.19+)

Если у вас Minecraft 1.19 или новее, можно использовать команду:

```minecraft
/structure save minecraft_structure -28 -60 -33 39 2 47
```

---

## 📋 Способ 3: WorldEdit (если установлен)

1. **Выделите область:**
   ```
   //pos1 -28 -60 -33
   //pos2 10 -59 13
   ```

2. **Сохраните схему:**
   ```
   //copy
   //schematic save minecraft_structure
   ```

3. **Файл будет в:**
   ```
   ~/.minecraft/schematics/minecraft_structure.schematic
   ```

## 🔍 После экспорта - сравнение структур

Когда получите `.nbt` файл, используйте скрипт для сравнения:

```bash
# 1. Установите библиотеку (если ещё не установлена)
pip3 install nbtlib

# 2. Автоматическое сравнение (пробует оба варианта ориентации)
./quick_compare.sh

# Или вручную (если знаете, что нужна перестановка осей):
python3 compare_structures.py minecraft.prefab.json \
  ~/.minecraft/saves/Новый\ мир/generated/structures/minecraft_structure.nbt \
  -28 -60 -33 \
  --swap-xz
```

**Важно:** 
- Offset `-28 -60 -33` нужен, чтобы выровнять координаты Minecraft с координатами prefab
- Если в Structure Block вы указали размеры как **47×2×39** (а не 39×2×47), используйте флаг `--swap-xz` для перестановки осей X↔Z
- Скрипт `quick_compare.sh` автоматически пробует оба варианта и покажет, какой даёт больше совпадений

## 📊 Что покажет сравнение

Скрипт покажет:
- Сколько позиций совпадает между структурами
- Какие блоки есть только в prefab
- Какие блоки есть только в Minecraft
- Процент совпадений

Это поможет понять, правильно ли структуры соответствуют друг другу.
