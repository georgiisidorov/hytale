# Ориентация осей в Minecraft и Hytale

## Проблема

В Minecraft Structure Block размеры указываются как **X × Y × Z**, но ориентация может отличаться от Hytale.

**Ваш случай:**
- Minecraft Structure Block: **47 × 2 × 39** (X × Y × Z)
- Hytale Prefab: **39 × 2 × 47** (X × Y × Z)

Это означает, что оси **X и Z поменяны местами**!

---

## Решение

Скрипты теперь поддерживают флаг `--swap-xz` для перестановки осей.

### Автоматическая проверка

Скрипт `quick_compare.sh` автоматически пробует оба варианта:
1. Без перестановки осей
2. С перестановкой осей X↔Z

Выберите вариант с **большим процентом совпадений**.

### Ручной запуск

```bash
# Без перестановки (обычный случай)
python3 create_block_mapping.py \
  minecraft.prefab.json \
  structure.nbt \
  -28 -60 -33

# С перестановкой осей X↔Z (ваш случай)
python3 create_block_mapping.py \
  minecraft.prefab.json \
  structure.nbt \
  -28 -60 -33 \
  --swap-xz
```

---

## Как определить правильную ориентацию

1. **Запустите оба варианта** (с `--swap-xz` и без)
2. **Сравните процент совпадений**
3. **Выберите вариант с большим процентом**

Скрипт автоматически выведет предупреждение, если процент совпадений низкий (<50%).

---

## Технические детали

При применении `--swap-xz`:
- Координаты Minecraft `(x, y, z)` преобразуются в `(z, y, x)`
- Это соответствует повороту структуры на 90° вокруг оси Y

**Пример:**
- Minecraft позиция: `(10, -60, 13)`
- После offset: `(38, 0, 46)` (относительно origin -28, -60, -33)
- После swap: `(46, 0, 38)` (меняем X и Z местами)
